# 0.1.0 - 2026-10-05

## New features
- Search a whole corpus of PDF documents in natural language: ask a question rather than guessing keywords, and the answer comes back as the passage that answers it.
  fr: Recherche en langage naturel dans tout un corpus de documents PDF : posez une question plutôt que de deviner des mots-clés, et la réponse revient sous forme du passage qui y répond.
- Every result opens the page of the original PDF with the passage highlighted on it, and the complete document stays one click away.
  fr: Chaque résultat ouvre la page du PDF original avec le passage surligné, et le document complet reste à un clic.
- Filters built from the documents' own metadata, declared by each corpus, with the year as a range.
  fr: Des filtres construits à partir des métadonnées des documents, déclarées par chaque corpus, avec l'année sous forme d'intervalle.
- A search is a place: the question and every filter live in the address bar, so a search can be bookmarked, shared or reopened.
  fr: Une recherche est un endroit : la question et tous les filtres sont dans la barre d'adresse, donc une recherche peut être mise en favori, partagée ou rouverte.
- Documents whose licence forbids redistribution can be shown page by page without being handed over.
  fr: Les documents dont la licence interdit la redistribution peuvent être affichés page par page sans être remis au lecteur.
